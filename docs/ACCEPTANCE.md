# 交付与验收

## 发给用户的结果

```text
已完成：本次实际跑通的功能。
打开这里：实际入口或可下载文件。
怎么用：修改哪项，点哪个操作，在哪里看结果。
已验证：真实样例、改变输入后的结果、重新打开记录。
运行位置：Muse 云电脑 / 外部环境 / 用户设备。
访问范围：Muse 内 / 云内 / 已测外部客户端 / 已测授权用户。
运行条件：需要的登录、额度、进程、有效期与恢复方式。
仍待完成：具体缺项；没有就写无。
```

## 各案例必须区分的结果

| 案例 | 首次验收 | 不能混为一谈 |
| --- | --- | --- |
| 视频 | 真实可播放文件、候选与选择、接点检查 | 页面展示旧视频 ≠ 新任务生成；云内出片 ≠ 外部 API 已打通 |
| 免费云部署 | 官方方案核对、资源是否开通、实际部署与访问 | 填完申请 ≠ 获得服务器；开发试用 ≠ 永久在线托管 |
| 今日精选 | 原来源读取依据、三个条目、按目标重排、记录保存 | 固定示例重排 ≠ 新内容采集；草稿生成 ≠ 已发布 |
| 晚餐补货 | 样例清单三组结果、保存恢复；可用时再验购物车 | 页面清单变化 ≠ 商家购物车已更改；核对 ≠ 付款 |

本仓库的发布校验只证明文档、链接和样例一致。每个用户环境里的真实生成、网站操作和外部部署，须由其 Muse 按上述步骤重新验证。
